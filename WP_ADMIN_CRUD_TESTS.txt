TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problème : Index vide (0 tours)
→ Vérifier connexion WP : DB::connection('wp')->getDatabaseName()
→ Vérifier count : WpPost::tours()->count()
→ Vérifier préfixe : config('database.connections.wp.prefix') = 'cFdgeZ_'

Problème : Erreur 500 lors création
→ Vérifier logs : tail -f storage/logs/laravel.log
→ Vérifier validation : StoreWpTourRequest
→ Vérifier WpTourRepository::createTour()

Problème : Tour créé mais metas vides
→ Vérifier WpTourRepository::updateTourMetas()
→ Vérifier mapping : destination → address, duration_text → duration_day

Problème : Slug non unique
→ Vérifier WpTourRepository::ensureUniqueSlug()
→ Doit auto-incrémenter : slug, slug-2, slug-3, etc.
