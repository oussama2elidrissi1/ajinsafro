## 3. TESTER UN VOYAGE

### Étape 1 : Configurer un Lieu de Départ
1. Aller dans Admin Laravel → Circuits → Tours
2. Sélectionner un voyage existant
3. Onglet "Lieux de départ"
4. Ajouter un lieu (ex: Casablanca, CMN)
5. Ajouter un vol pour ce lieu
6. Enregistrer

### Étape 2 : Configurer des Dates
1. Même voyage, onglet "Dates disponibles"
2. Ajouter plusieurs dates (ex: 2026-03-15, 2026-03-20, 2026-03-25)
3. Enregistrer

### Étape 3 : Vérifier sur WordPress
1. Aller sur la page du tour sur le site WP
2. Vérifier que le select "Starting from" affiche Casablanca
3. Sélectionner Casablanca → Les vols doivent s'afficher
4. Vérifier que le champ date n'accepte que les dates configurées

## 4. ROLLBACK (Si Problème)

Si vous devez annuler les migrations :

```powershell

php artisan migrate:rollback

# Ou rollback spécifique (3 migrations)
php artisan migrate:rollback --step=3
```

## 9. PROBLÈMES COURANTS

### "Table already exists"
```powershell
# Vérifier si les tables existent déjà
php artisan db:table wp_aj_travel_departure_places

# Si oui, pas besoin de migrer à nouveau
# Sinon, réessayer la migration
```

### "Class not found"
```powershell
# Regénérer l'autoload
composer dump-autoload
```

### Données ne s'affichent pas sur WP
1. Vérifier que le tour a un `laravel_id` ou `aj_laravel_id` dans wp_postmeta
2. Vérifier que les données existent dans les tables
3. Vérifier les logs : storage/logs/laravel.log

### JavaScript ne fonctionne pas
1. Ouvrir la console du navigateur (F12)
2. Vérifier les erreurs JavaScript
3. Vérifier que les attributs data-* sont présents sur #aj-searchbar
