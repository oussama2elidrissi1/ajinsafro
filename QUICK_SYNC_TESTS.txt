Problème : WP → Laravel ne fonctionne pas
Solution : 
  1. Vérifier Settings WP : Enable WP → Laravel Sync (coché)
  2. Vérifier Laravel Webhook Token est rempli
  3. Vérifier Laravel .env : SYNC_WEBHOOK_TOKEN existe
  4. Tester manuellement :
     curl -X POST https://booking.ajinsafro.net/api/sync/wp-to-laravel \
       -H "Authorization: Bearer YOUR_TOKEN" \
       -H "Content-Type: application/json" \
       -d '{"action":"upsert","entity_type":"tour","source":"wp","wp_post_id":123,"title":"Test","slug":"test","status":"publish","sync_hash":"abc"}'

Problème : Laravel → WP ne fonctionne pas
Solution :
  1. Vérifier Laravel .env : WP_SYNC_URL correct
  2. Vérifier Laravel .env : SYNC_TOKEN existe
  3. Vérifier Settings WP : HMAC Secret correspond
  4. Vérifier Settings WP : Enable Sync (coché)
  5. Tester manuellement depuis Laravel :
     php artisan tinker
     >>> app(\App\Services\Sync\WpSyncService::class)->upsertVoyage(\App\Models\Voyage::first());

Problème : Package Builder ne s'affiche pas
Solution :
  1. Vérifier Settings WP : Auto-inject Package Builder (coché)
  2. Vérifier le tour a _aj_laravel_voyage_id :
     get_post_meta($post_id, '_aj_laravel_voyage_id', true);
  3. Vérifier l'API Laravel :
     curl https://booking.ajinsafro.net/api/public/tours/ID/package-state
  4. Vérifier les assets sont chargés (F12 Network)

Problème : Boucle infinie
Solution :
  1. Vérifier AppServiceProvider : SyncContext est singleton
  2. Vérifier VoyageObserver vérifie $syncContext->isFromWp()
  3. Vérifier TourSyncer utilise _aj_sync_lock
  4. Vérifier les hashes :
     Laravel : $voyage->wp_sync_hash
     WP : get_post_meta($post_id, '_aj_sync_hash', true)
