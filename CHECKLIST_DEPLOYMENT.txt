┌────────────────────────────────────────────────────────────────────────────────┐
│ ⚠️ EN CAS DE PROBLÈME                                                          │
└────────────────────────────────────────────────────────────────────────────────┘

Problème : DB toujours mauvaise
→ Vérifier .env : DB_DATABASE=ajinsafronet_ajinsafro
→ php artisan config:clear && php artisan config:cache
→ Redémarrer PHP-FPM

Problème : 401 Missing signature
→ Vérifier secrets identiques Laravel/WordPress
→ Vérifier header X-AJ-Signature présent

Problème : 401 Invalid signature
→ Secrets probablement différents
→ Reconfigurer Settings WordPress avec exact SYNC_SECRET

Problème : Boucle infinie
→ Vérifier logs _aj_sync_lock
→ Vérifier SyncContext Laravel

Problème : Import échoue
→ Vérifier WP_DB_* dans .env
→ Vérifier connexion 'wp' accessible
