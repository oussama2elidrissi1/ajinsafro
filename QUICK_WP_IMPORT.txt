WordPress → Laravel Mapping :

┌─────────────────────┬────────────────────────────────────────────────────────┐
│ Champ Laravel       │ Source WordPress                                       │
├─────────────────────┼────────────────────────────────────────────────────────┤
│ wp_post_id          │ wp_posts.ID                                            │
│ name                │ wp_posts.post_title                                    │
│ slug                │ wp_posts.post_name (avec vérification unicité)         │
│ description         │ wp_posts.post_content                                  │
│ accroche            │ wp_posts.post_excerpt                                  │
│ destination         │ st_tours.address OU postmeta(address)                  │
│ duration_text       │ st_tours.duration_day OU postmeta(duration_day)        │
│ price_from          │ st_tours.adult_price > min_price > postmeta (1er > 0)  │
│ currency            │ 'MAD' (fixe)                                           │
│ status              │ 'actif' si publish, sinon 'brouillon'                  │
│ wp_synced_at        │ now()                                                  │
│ wp_sync_hash        │ SHA256 des données (pour détecter changements)         │
└─────────────────────┴────────────────────────────────────────────────────────┘


╔════════════════════════════════════════════════════════════════════════════════╗
║                       TROUBLESHOOTING                                          ║
╚════════════════════════════════════════════════════════════════════════════════╝

Problème : "0 tours WordPress trouvés"
Solution : 
  - Vérifier DB_DATABASE dans .env (doit être ajinsafronet_wp_tkrpc)
  - Vérifier que les tables cFdgeZ_posts existent
  - Vérifier post_status='publish'

Problème : "Table cFdgeZ_posts doesn't exist"
Solution :
  - La base WordPress n'est pas accessible
  - Vérifier connexion DB
  - Vérifier le préfixe des tables (cFdgeZ_)

Problème : "Duplicate entry for key 'voyages_slug_unique'"
Solution :
  - Normalement géré automatiquement (ajoute -ID au slug)
  - Si persiste, vérifier les slugs existants

Problème : Import lent (> 10s pour 26 tours)
Solution :
  - Normal, requêtes optimisées déjà en place
  - Vérifier les indexes sur voyages.wp_post_id
